01 ¿Qué es?

Un lanzador universal para Chromebooks. Detecta automáticamente el motor de cada juego de RPG Maker o Ren'Py que tengas, descomprime el .zip si hace falta y lo abre con el runtime correcto. Sin emuladores, sin tocar nada del juego, sin entornos raros.

🛰️ Detección automática

Mira los ficheros del juego y elige el motor exacto sin que tengas que configurar nada.

📦 Descomprime solo

Extrae el .zip al vuelo, una sola vez, con marcador de integridad.

🖥️ Interfaz gráfica

App nativa de Chrome OS con botón para detener servidores y borrar comprimidos.

⚡ Visor WebKit ligero

Para juegos web pesados: se abren en un visor WebKit propio, con menos memoria que el navegador completo.

🛡️ Sin solapamientos

Un servidor web a la vez: al abrir otro juego, el anterior se cierra solo.

🔍 Diagnóstico

El visor guarda los errores de consola JS en <juego>.webkit.log para encontrar plugins rotos.

03 Instalación

Desde el terminal de Linux de tu Chrome OS (Crostini):

git clone https://github.com/AsterrZep/rpgmaker-launcher.git
cd rpgmaker-launcher
chmod +x install.sh
./install.sh

El instalador configura las dependencias, instala EasyRPG, compila mkxp-z y crea el acceso directo. Busca RPG Maker Launcher en las apps de Linux (en Chrome OS puede hacer falta cerrar sesión o reiniciar el contenedor para que aparezca).

04 Cómo funciona

Basta con dejar tus juegos (en .zip o ya descomprimidos) dentro de la carpeta del lanzador:

~/Games/ ├── rpgmaker-launcher.sh # versión de terminal ├── rpgmaker-launcher-gui.py # interfaz gráfica ├── games/ # juegos descomprimidos (auto) │ └── Mi_Juego/ └── Mi_Juego.zip # se extrae solo al lanzarlo
  • El lanzador detecta el motor y lo abre con el runtime adecuado.
  • Los juegos web (MZ/MV) se sirven en localhost. Se abren en el navegador o en el visor WebKit ligero (marca la casilla "Visor WebKit (más ligero)"), que consume menos memoria en juegos pesados.
  • Detener servidor apaga el servidor web en cualquier momento.
  • Advierte si una descarga o descompresión quedó incompleta.
  • Si un juego no arranca, el visor guarda los errores de consola JS en <juego>.webkit.log y puede diagnosticar el problema con --test.
