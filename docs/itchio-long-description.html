A universal desktop launcher for Linux. It started life as a Chrome OS app and now runs on any Linux desktop: it auto-detects the engine of every RPG Maker or Ren'Py game you drop in, extracts the .zip if needed and opens it with the correct runtime — no emulators, no fiddling, nothing in the game itself is ever touched.

What it does

Auto engine detection
MZ, MV, XP, VX, VX Ace, 2000, 2003 and Ren'Py — nothing to configure.
One-click extraction
.zip files are extracted on the fly, once, with an integrity marker.
Lightweight WebKit viewer
Heavy web games open in their own viewer instead of the full browser: less RAM, faster start.
Fast HTTP server
Multithreaded, with cache headers and the right MIME for .wasm — no stutter on big games.
Plugin manager
Find and disable heavy or nw.js-only plugins. Can cut the game loop time by up to 31%.
Saves as real files
Web saves land in each game's save/ folder as .rpgsave/.rmmzsave — exportable and editable, with GUI backups.
JoyPlay-style cheats
Press F8 in MZ/MV: gold, HP/MP, items, variables, switches, teleport and a code console.
Gamepad + shortcuts
Play MZ/MV with a controller; remap FPS, screenshot, fullscreen, zoom and reload keys.
Built-in decrypter
Decrypt XP/VX/VX Ace/MV/MZ archives for modding and translation.
Error diagnostics
A --test mode tells you exactly why a game won't boot (JS errors, load time, title screen).
Terminal & GUI
A classic terminal menu and a clean graphical app — both included.
Incomplete-download guard
Detects cut-off downloads and half-extracted games before you play them.

Installation

Pick any one:

# Debian / Ubuntu (recommended — small)
sudo apt install ./rpgmaker-launcher_0.2.0_amd64.deb
# AppImage (portable, includes its own Python)
chmod +x rpgmaker-launcher-0.2.0-x86_64.AppImage && ./rpgmaker-launcher-0.2.0-x86_64.AppImage
# Flatpak (GNOME sandbox — first run downloads ~2-3 GB of runtime)
flatpak install rpgmaker-launcher-0.2.0.flatpak

Short on disk space? Use the .deb or the AppImage — they are much smaller than the Flatpak.

How to use it

  1. Drop your games (.zip or already-extracted folders) inside ~/Games/.
  2. Open RPG Maker Launcher from your desktop's app menu.
  3. Click a game's card… and play.
~/Games/
  ├── games/  # extracted games (automatic)
  │   └── Your_Game/
  └── Your_Game.zip  # extracted on launch

Good to know

✓ Saves survive
Each web game gets a fixed local port, so browser saves never get "lost". A bridge writes them to real files you can back up or edit.
✓ Cheats built-in
F8 opens a floating cheat menu in MZ/MV games: gold, full HP/MP, items, variables, switches, teleport and a JavaScript console.
✓ One server at a time
Launch another web game and the previous local server closes itself — no port conflicts, no leftovers.

Requirements

  • Any Linux with a desktop (including Chrome OS with Linux / Crostini enabled).
  • Python 3 (comes with every distro).
  • unzip.
  • XP/VX/VX Ace: mkxp-z (compiled automatically by the installer).
  • 2000/2003: easyrpg-player (installed by the installer).
